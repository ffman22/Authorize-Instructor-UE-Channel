# Script format (every script follows this)

Source: Gemini's research in Drive (`01_MASTER_STRATEGY`, both `05_` docs, `06_ALGORITHM_UPDATES`) on creator advice videos and five reference videos. Their view counts and algorithm claims were not re-checked. Owner rules and `docs/research_rules.md` win.

## First rule: result first
1. **0:00-0:03** Frame 0 shows the finished result in motion (or broken vs fixed side by side). Say the core term aloud while it shows. No greeting, no logo, no face-only opening in a Short.
2. **By 0:05** Open loop: name the payoff the viewer gets by staying ("by pass 3 the feet lock").
3. **Then** credibility, about 3 s (2 s in micro-tips), over the demo, never a separate bio pause.
4. **Only then** the problem, the steps and the proof.
5. **End** Result again, one next step, call to action.

## Every script delivers
- A real animator's pain point.
- A tactic that is not obvious, from production experience.
- A visual the viewer understands at once.
- Something to try in Unreal today.
- A comment trigger: a clear stance against a bad habit, a precise framing, or a known name (Unreal Engine 5, Lyra, Assassin's Creed as experience only). No insults to beginners.

## Short formats
| Format | Length | Beats |
|---|---|---|
| Micro-tip | 20-30 s | result 0-2, credibility 2-4, one fix 4-22, arrow and CTA 22-27 |
| Progressive escalation | 50-60 s | result 0-3, credibility 3-6, the same clip 3 times 6-48 (`STEP 1/3` banner, one layer per pass), arrow and CTA 48-56 |
| Series "AAA UE5 Secret:" | 20-35 s | `docs/series_ue5_secret.md` |
| Reel breakdown | 45-55 s | same shot 3 times: anticipation, contact and hitstop, cancel and recovery; never tag non-Unreal footage as Unreal |

## Editing
- Fixed top banner, 2-4 words.
- Captions of 1-2 words, changing every 1-1.5 s.
- No static panel over 2 s: zoom on one node, then back to the character moving.
- Cut every 2-3 s; trim any old "hello everybody".
- YouTube: last 2 s, arrow to the Related Video, only when that video exists.
- Plus the cut-plus-splash limit of 60 s.

## Long format (12-16 min)
0:00 payoff in engine (editor visible before 0:15), 0:10 credibility reel (11-13 s), 0:23-0:35 workshop pitch, open loop for something delivered at the end, chapters, a visual change at least every 15 s, overlays over the moving viewport instead of slides, stress test and CTA at the end.

## Titles
No hashtags. Start from the viewer's pain or the result, include Unreal Engine 5 or UE5 when true.
